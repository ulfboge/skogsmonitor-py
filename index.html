Den här filen ligger i repo-rot. Automatisk omdirigering till docs/ sker bara på localhost / 127.0.0.1 (lokal server från klonad repo-rot).

GitHub Pages med Actions: kartan ligger på webbplatsens rot, t.ex. ulfboge.github.io/skogsmonitor-py/ — använd inte …/docs/ (404).

Manuellt: docs/ (t.ex. om du publicerar hela repot och docs/ finns som mapp).
